# Books-Downloader — Privacy Policy / Datenschutzerklärung / Политика конфиденциальности

[English](#english) · [Deutsch](#deutsch) · [Русский](#русский)

## English

Books-Downloader runs on the user's device. The developer does not collect,
store, or receive personal data through the extension. There is no tracking,
usage analytics, or transmission of data to the developer's servers.

The extension processes book information and download links locally.
The download queue and progress are stored in local browser storage;
downloaded files remain on the device. Local extension data is removed
when the extension is uninstalled. Users can delete downloaded files themselves.

To retrieve and download the requested content, the browser connects to
akniga.org and the file servers linked there. These providers receive
connection data technically necessary for these requests, such as the IP address.
Requests to akniga.org may use the existing website session.
These providers' own privacy policies apply to their data processing.

Contact: [GitHub project](https://github.com/phoenixrvd/Books-Downloader/issues)

## Deutsch

Books-Downloader läuft auf dem Gerät des Nutzers. Der Entwickler erhebt,
speichert oder erhält keine personenbezogenen Daten durch die Erweiterung.
Es gibt kein Tracking, keine Analyse des Nutzungsverhaltens und keine
Übermittlung an Server des Entwicklers.

Die Erweiterung verarbeitet Buchinformationen und Download-Links lokal.
Die Download-Warteschlange und der Bearbeitungsstand werden im lokalen
Browserspeicher gespeichert; heruntergeladene Dateien bleiben auf dem Gerät.
Die lokalen Erweiterungsdaten werden bei der Deinstallation entfernt.
Bereits heruntergeladene Dateien können vom Nutzer selbst gelöscht werden.

Zum Abrufen und Herunterladen der gewünschten Inhalte verbindet sich der
Browser mit akniga.org und den dort verlinkten Dateiservern. Dabei erhalten
diese Anbieter technisch notwendige Verbindungsdaten, etwa die IP-Adresse.
Anfragen an akniga.org können die bestehende Sitzung der Website verwenden.
Für die Datenverarbeitung dieser Anbieter gelten deren Datenschutzbestimmungen.

Kontakt: [GitHub-Projekt](https://github.com/phoenixrvd/Books-Downloader/issues)

## Русский

Books-Downloader работает на устройстве пользователя. Разработчик не собирает,
не хранит и не получает персональные данные через расширение.
Расширение не отслеживает действия пользователя, не анализирует использование
и не передаёт данные на серверы разработчика.

Расширение обрабатывает информацию о книгах и ссылки для скачивания локально.
Очередь загрузок и состояние их выполнения сохраняются в локальном хранилище
браузера; скачанные файлы остаются на устройстве. Локальные данные расширения
удаляются при его удалении. Уже скачанные файлы пользователь может удалить сам.

Для получения и скачивания выбранных материалов браузер подключается
к akniga.org и файловым серверам, ссылки на которые размещены на сайте.
Эти сервисы получают технически необходимые данные соединения, например IP-адрес.
Запросы к akniga.org могут использовать существующую сессию сайта.
Обработка данных этими сервисами регулируется их собственными политиками
конфиденциальности.
